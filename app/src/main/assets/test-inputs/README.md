# Capability Test Inputs

This directory is reserved for small local-only proof inputs used by the central
AI-Engine diagnostics. Large or sensitive media should not be committed here.

Expected proof inputs:

- `image-proof.jpg` for IMAGE and MULTIMODAL.
- `ocr-proof.png` for OCR.
- `stt-proof.wav` for STT.
- `audio-proof.wav` for AUDIO.
- `video-proof.mp4` for VIDEO.

Readiness still requires installed-device proof. File presence alone is not
capability readiness.
